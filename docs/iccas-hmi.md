# 后处理双站 HMI

两个页面作为 PLC-Sim 的本地设备操作面板，通过 Python 通信服务读写真实 OPC UA 节点。

## 启动

1. 双击 `start_iccas_devices.command` 启动两台设备；已经运行时无需重复启动。
2. 双击 `start_iccas_hmi.command`，保持终端开启。
3. 打开喷雾站 http://127.0.0.1:18866/spray.html 或过滤站 http://127.0.0.1:18866/filter.html 。

HTML 源文件位于 `gui/static/iccas-spray.html`、`gui/static/iccas-filter.html`，共用 `iccas-hmi.css` 和 `iccas-hmi.js`。不要直接双击 HTML 控制设备，浏览器需要本地桥接服务。无需 Prosys Professional 许可。

默认连接本机 OPC UA 4855、4856 端口。可用 `start_iccas_hmi.command --port 18867 --base-port 4855` 改变端口。服务仅监听本机。

喷雾站真机只读监控使用：

```bash
./start_iccas_hmi.command --mode real --read-only \
  --spray-endpoint opc.tcp://192.168.1.88:4840
```

真机模式会从 `ns=4;s=OPC` 浏览并映射汇川 PLC 节点；`--read-only` 会在服务端拒绝所有写入请求，页面上的启动、复位、模式和参数写入也会锁定。真机点表命名与设备包有三处适配：接口合同标记在 PLC 上叫 `接口版本`（当前值为 `V001`），工位模式点叫 `实验工位启用0_AB1_A2_BPCtoPLC`，动作控制后缀用 `_` 代替 `.`。

## 操作

- 真机动作状态尚在联调时，“启动动作”暂不以 `idle` 作为按钮启用条件；离线、只读、需要恢复、存在未保存参数、未选动作或 Trigger 已置位时仍禁止启动。
- 真机 `_状态` 为空时，页面根据 Trigger、Complete、取消、命令号、已接受命令号和错误码推导动作状态。搬运动作在 Trigger 到 Complete 之间显示“搬运机构 · 执行中”；现有点表没有夹爪占用检测，因此空闲时明确显示“夹爪占用未知”。
- 总览显示料仓、工作位、夹爪、真空箱占用、动作通道和报警；容器图案表示占用，不表示真实液位。
- 喷雾工位模式：0=A+B，1=仅A，2=仅B。点击“应用模式”写入设备。
- 手动操作：选择动作、填写适用的仓位号码，点击启动。服务生成递增命令号，设备完成后自动复位本 HMI 提交的握手。
- 配方参数：修改后统一写入；有未写入参数时禁止启动动作。设备忙碌或需要恢复时禁止写配方。
- 取消会中断仿真动作，可能进入位置恢复状态。软件取消不是硬件急停。
- 位置恢复：复位动作握手，读取当前位置，逐项选择各位置的实际容器，勾选确认后提交。设备检查物料守恒、类型和位置，再更新恢复应答号；查看页面上的错误或应答结果。
- 通信中断后自动重连，不自动重发动作。页面事件仅保存本次服务运行期间最近100条。

演示时由一个控制端发动作；接入 Uni-Lab 后，不要同时在 HMI 和 Uni-Lab 中下发相互冲突的命令。此版覆盖设备手动操作、参数、监视与恢复，不包含自动编排整套实验、PLC程序编辑或真实工艺闭环。参数使用当前仿真器的校验规则，尚未补齐点表中所有数值上下限联锁。

喷雾站已增加 A/B 原料罐及反应罐工作位取料、库位放料，共21个动作、349点。库位放料回到容器原始仓位，目标必须为空。旧设备日志新增动作记录时保留物料位置和原动作结果。页面上的取出/放入及动作按钮用于选择动作，再按“启动动作”执行。

汇川喷雾站真机当前只暴露 326 点：173 个供应商点、16 个扩展握手点和 137 个动作控制点都在，但设备包里的 `物料位置JSON`、`恢复位置JSON` 和 21 个 `上次结果JSON` 尚未提供。真机模式会用料仓/工作位检测位合成位置视图；位置恢复只递增 `恢复请求号`，不写 `恢复位置JSON`。
